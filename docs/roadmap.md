# Ovxa roadmap

Phases are ordered by what depends on what. They carry no calendar commitments.

## Phase 1: Foundation (in progress)

- Brand system built from the logo's own pixels.
- Public site with live Solana readings and a records register.
- Written design: whitepaper, architecture, security policy.
- Gates that prove the site behaves correctly with and without a stated address.

Exit condition: the site and documents are stable enough that the program team can build against them.

## Phase 2: Open grid

- Program written, reviewed and deployed to Solana mainnet.
- Contract address stated in the register, which switches on the copy slot at the top of the site.
- First cells claimable.
- Public repository linked from the site once its record is stated.

Exit condition: an outside party can claim a cell and read it back from the ledger using only public tools.

## Phase 3: Signals

- Signal catalogue published with the trust model for each entry.
- Publisher tooling released so third parties can feed readings.
- Silent-publisher flag introduced.

Exit condition: at least one signal is fed by a publisher outside the core team.

## Phase 4: Hand-off

- Upgrade rights move from the core team to cell holders.
- Parameter changes follow a written process with a public waiting period.
- Core team keeps no unilateral power over the program.

Exit condition: the upgrade authority is a holder-controlled account and the site's records say so.

## Not planned

- An order book or any trading venue.
- Custody of user funds.
- Promises about token performance.
